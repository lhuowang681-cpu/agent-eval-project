# 消融：发现能力与审核接受分开

所有新 48 例数据来自冻结的单作者合成集。C/D 以下均为人工候选回放，不是真实 LLM。完整数值与分母在 EXPERIMENT_RESULTS 和 results/summary.json。

| 配置 | 正确/错误/不可判 | 有效覆盖 | False Support | False Gap |
| --- | --- | --- | ---: | ---: |
| 无 LLM，仅 B 增强规则 | 22/0/0 | 19/28 | 无审核阶段 | 无审核阶段 |
| B + 新审核 | 22/0/0 | 19/28 | 0 | 0 |
| 人工直接候选 | 28/6/13 | 22/28 | 无审核阶段 | 无审核阶段 |
| 人工候选 + 引用存在性 | 27/6/12 | 22/28 | 20 | 0 |
| 人工候选 + 原审核 | 17/4/4 | 14/28 | 8 | 8 |
| 人工候选 + 新完整审核 | 17/0/0 | 14/28 | 0 | 8 |

引用有效可以排掉伪造/缺失，但挡不住合法基期被误判、冲突结果、错误语义和强行根因。完整审核后候选数下降 45→17，同时去除 20 个不受支持接受，并丢掉 8 个原本人工证据足够的正确语义观察。这既有安全收益，也有真实覆盖代价。

原审核→新审核移除 8 个不受支持接受，没有进一步损失本集的正确接受：正确数均为 17、False Gap 均为 8。由此支持两个缺陷修复的有限合理性；不能据单作者集合估计线上误报率。

B 的 22 个输出全部通过新审核；人工候选审核只留下 17 个。五个差额涉及候选原文/Scope/结论强度等因素，不能把它解释成模型生成能力弱于规则，因为并未运行真实 C。共同事实解析也让 B 与审核天然更一致，这个设计局限公开保留。

## 覆盖与风险离散点

- 引用层：输出案例 42/48，接受声明 45，False Support 20/45。
- 原完整审核：输出案例 22/48，接受声明 25，False Support 8/25。
- 新完整审核：输出案例 14/48，接受声明 17，False Support 0/17。

不使用模型自报置信度调阈值；这只是审核层的离散操作点，不是已校准风险曲线。没有把“全弃权准确率”写成 100%；零输出的准确率在指标测试中要求 null。

## LLM 净增量

新集合没有真实模型，净增量为 **未测量**。人工候选经审核的有效命题相对 B 的新增部分为 0；旧六次真实输出同输入复核也为 0，但后者只覆盖已见简单结构化场景。不能将两种“0”外推为“LLM 永远没用”。

要证明增量，需新增模型预算、真正的 C 原始输出、人工复核和针对中文/同义/单位关系的可追溯验证。当前八条 False Gap 说明即使模型提出这类候选，现审核也未能承接。这里尚未解决，不以第二个 LLM 投票来假装有独立证据。

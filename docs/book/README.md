# Agent 轨迹评测与故障归因 · 工程教材版 2.1

打开 [index.html](index.html)，用普通浏览器阅读。无须安装依赖、启动服务或连接网络；也可以把这一个 HTML 文件复制到其他位置。

## 阅读内容

- 新增独立项目总介绍：业务、输入输出、技术职责、设计重点与面试概述。
- 6 章、18 节完整工程正文：场景、术语、数据与状态、职责、取舍、故障与验证。源码和原任务清单默认折叠，读正文无需逐行看代码。
- 依据指定仓库 Skills 适配的先教后练、逐题复习、完整参考回答与模拟面试流程。
- 新增 A—J 十阶段40个搭建任务：参考基础、走通状态与新增实现分别记录；每任务有依赖、输入输出、设计理由、反例和完成标准。由进度表可直接跳到任务，再进入对应教材。
- 平台运行机制补充、术语速查、15～20 天学习路线和下一阶段离线闭环 Spec 目录。
- 96 个参考文件及相关 Spec 的内嵌文本；点击入口可在书内查看行号与来源 hash，不会执行参考脚本。

## 阅读功能

左侧目录与全书目录均可跳转，页尾可前后翻节，浏览器后退可返回上次页面。支持全文搜索、字号和配色、个人笔记、任务自评、学习记录导出 / 合并导入，以及打印全书。

笔记、阅读位置与自评状态保存在当前浏览器。不同浏览器 / 文件位置之间不保证共享记录，移动前请导出备份。浏览器不支持持久存储时，页面会提示使用导出。

当前是依据参考材料整理的教学阅读版。练习勾选是个人自评，不是实验通过证明；书中教学例子与数字不属于程序实测。阅读器完成不代表自己的离线归因应用已经实现。

旧版导出的学习记录仍可导入，保留 E01—E18 身份。新教材不会因导入旧勾选生成教练分数；聊天真实评估在 `docs/learning/LEARNING_PROGRESS.json`，初始均未评估。教材的静态记录页是生成时快照，不是浏览器与聊天自动同步服务。

## 来源与维护

当前采用更新后的 `HANDOFF.md` 与根目录总计划第 18 节：第二项目每天约 5 小时，15 天首轮、18～20 天巩固。原任务的 45～90 分钟仅作首轮走查参考。阅读版纠正了部分任务中误写的兄弟项目根路径；原参考快照未修改。

- `content.json`：18 节教学导引和例子。
- `lessons/`：总介绍与 E01—E18 的主教材正文，后续扩写优先修改这里。
- `../learning/`：项目知识点、复习参考回答、真实学习历史、面试规则和方法来源。
- `reader.css`、`reader.js`：阅读界面与本地交互。
- `build.mjs`：从当前 Spec、任务文件及参考快照生成单文件 HTML。
- `BUILD_INFO.json`：生成版本、页数、跳转和参考 hash 检查结果。

维护时，在本项目根目录执行：

```text
node docs/book/build.mjs
```

生成器只读取文档和参考文件，不导入参考 Python / TypeScript 代码。它会核对 96 个参考 hash、18 个任务和内部导航。任何参考 hash 不符都会停止。根目录总计划仅作为只读排期来源。

搭建进度的任务定义和事实记录在 `docs/roadmap/`。先运行 `node docs/roadmap/generate.mjs` 生成进度表与任务Spec，再生成阅读版。完成状态要求真实完成日期及本项目中存在的证据文件。阅读版中的搭建状态是生成时快照，不从浏览器勾选自动更新。

正文或 Spec 修改后，需要重新生成阅读版。单文件 HTML 中包含生成时的源码文本快照，不会实时跟随外部文件变化。

跨电脑打包运行 `python docs/book/package.py`，只收录手册及明确选定的项目学习资料，不读取浏览器私人笔记或目录外凭证。阅读无需运行任何这些脚本。

本轮完成了静态结构、链接、脚本语法与参考 hash 检查。内置浏览器无法访问本机预览且阻止本地文件协议，因此没有声称完成浏览器视觉与交互实测。

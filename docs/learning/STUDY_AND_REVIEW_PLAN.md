# 学习与复习怎样推进

按本项目每天约5小时安排，15个学习日完成首轮，必要时用到18—20个学习日。D1表示真正开始学习的第一天，不是教材生成日。日程是调整用的基线，不因到了某天就自动算完成。源码只用于必要核对，主要学习工程设计、数据与状态、失败处理和验证。

## 每天只有一张学习卡

最新节奏（2026-10-23）：基础概念合并快速带过，按完整工程段落讲授，不每个知识点停下来问。时间少时优先一段完整流程和关键设计，不把主线拆成大量简单问答。只在必要处做综合检查；局部卡住就局部补讲，再继续。实际记录按段落收尾批量保存。

开始时对教练说：“开始今天学习，我有5小时。”教练先读取学习历史、复习队列和搭建记录，再列出今日复习、今日新课、预期小产物和收尾标准。首日没有已学记录，先讲项目总介绍，再进入A1；不先考没学过的内容。

| 每日用时参考 | 做什么 | 看得见的结果 |
| --- | --- | --- |
| 30分钟 | 复习到期内容，优先前置缺口 | 一次只问一道；不会就补讲，最多约3个点 |
| 120分钟 | 学今天的一组相关任务，先完整讲解 | 能说出问题、输入输出、主要流程与设计理由 |
| 90分钟 | 把一个案例从输入推到输出 | 流程图、状态表、手算结果或已有程序的验收记录，任选合适形式 |
| 45分钟 | 试着复述，再补讲遗漏 | 能解释一个设计取舍和一个失败反例 |
| 15分钟 | 保存真实进度，排下次任务 | 今日记录、待补点、复习日期、下一任务 |

时间可按当日状态调整，不要求连续学满。一天是一组相关任务，不按“每天必须打几个勾”推进。复杂点可能占两天，简单且紧密相关的点可以合并。只有2小时就缩小新课范围，保留短复习和一个完整例子。

| D6—D8 | E责任候选收尾、F去噪分类与证据 | 出错、恢复、责任分别依据什么；分类为何还要校验 |

沿用[搭建路线](../roadmap/BUILD_ROADMAP.md)的依赖。首轮目标是工程主线走通并交付选定的离线增量，不承诺15天掌握全部参考代码。代码实现和个人理解分别记录；Codex写完代码不代表用户已学会。

## 复习怎样排

先采用“学后第1、3、7天”的便于执行的规则，后续按实际回忆调整，不把它当作固定最优间隔。以实际讲授日为起点：例如周一学过，安排周二、周四、下周一；没有真正学过的主题不预设复习成绩和到期日期。

每次换个小场景，检查三件事：能否讲出主流程，能否解释一个为什么，能否判断一个失败情况。不是逐字背教材。复习一次一题，用户说不会就直接补完整解释。

- **能独立讲清并判断反例**：记录本次表现，保留下一次间隔复习。
- **需要提醒或查材料**：记录具体遗漏，次日优先短复习；不必把整章重学。
- **关键概念或前置流程不清**：先补一个更简单的完整例子，暂停依赖该点的新内容；补讲后次日再看。

如果错过复习，恢复学习时优先“阻塞当前任务的缺口→最近答错→逾期最久”。每天复习约30分钟，必要时到45分钟；剩余顺延，不让积压挤掉全部新课。同一知识点的多次逾期合并为一次检查，再按这次真实表现重排，不连考三遍补账。日历上的间隔到了但没有会话，不代表已经复习。

## 怎么判断完成，什么时候调计划

学习任务看实际产物：能走一遍输入到输出，说明至少一个工程理由，判断一个失败反例，并留下可查看的记录。阅读勾选只表示自评。完成判据用逐任务规格，评分不是打勾的必要条件。

每3个学习日做一次约15分钟盘点，计入当天收尾：哪些任务真的走通、哪些前置点仍需帮助、个人增量是否具备运行证据。若连续两次在同一前置点卡住，下一天减少新课、换例子补讲；不靠延长阅读量赶进度。首轮后的巩固只围绕暴露的问题和实际验证安排。

正式模拟面试在已有对应学习和个人产物后，由用户提出再开始。平时收尾用轻量复述，不每天做压力面试。项目介绍中的实现与成绩必须有实际依据。

## 谁负责记，换电脑怎样接续

用户在有项目文件访问能力的聊天里说“今天先到这里”，教练保存真实发生的内容：讲过什么、实际回答、具体遗漏、产物路径、下次任务和复习日期。未作答就不评分；未验收就不标完成。用户只需核对有没有记错，不用手工维护多张表。

- `LEARNING_PROGRESS.json`：真实问答历史、评价及`reviewQueue`待复习项；讲授但未作答的记录明确标注，不伪造回答。
- `../roadmap/BUILD_PROGRESS.json`：任务走通与个人实现的分别验收记录；`BUILD_PROGRESS.md`是生成后的可读视图。
- 书内笔记：自己的阅读记录，可导出，不能自动当作教练已经检查过。

纯离线阅读时，自己记下学过的主题、疑问和尝试的回答，回到聊天提供这些内容后再更新。聊天助手不会在会话外自动监测阅读或主动催复习。换电脑带走更新后的整个项目学习文件夹及浏览器导出的笔记；旧ZIP是打包时快照，后来的进度需要另行携带或重新打包。

新聊天可以直接说：“先读HANDOFF、agent-eval-coach和两个进度JSON，按到期复习和下一任务安排今天，不从头重来。”

## 怎样更新

1. 首先确认是在更新走通进度，还是新增代码进度。两个状态不能互相代替。
2. 教学走通完成：留下该任务的输入到输出产物、失败反例及真实复述/核对记录；纸面预测明确标注，不强制部署完整企业平台。只发教材不打勾。
3. 工程实现完成：拟建文件已实际实现，运行必要验收并保存真实配置、输入、输出和限制。仅有源码不打勾。
4. 编辑 BUILD_PROGRESS.json 的对应任务：status、日期和 evidence。完成状态必须有本项目内真实存在的证据文件；不补造过去记录。history 追加实际发生的变更依据。
5. 运行 `node docs/roadmap/generate.mjs` 更新表格。再运行 `node docs/book/build.mjs` 更新阅读器快照；需要换电脑时重新打包。

不从浏览器勾选自动同步到这里，也不从任务打勾自动生成教练分数。当前没有用户走通记录，保持未开始。

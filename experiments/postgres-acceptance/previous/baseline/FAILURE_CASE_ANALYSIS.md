## 仍存在的八条 False Gap

| Case | 正确观察 | 为什么拒绝 |
| --- | --- | --- |
| 10 | 新一轮中文改查2026，仍查2025 | 没有可信结构化闭集，不能自动解析意图 |
| 11 | 中文只查2025，实际2024 | 同上 |
| 15 | 未发货工具结果，被回答“已经发货” | 最终答案非结构化 JSON |
| 16 | awaiting_dispatch 被解释为已经出库 | 同义表达未有可验证映射 |
| 17 | shipping_state 与 status 语义对应 | 不同字段的映射不在合同内 |
| 19 | 1200分被回答120元 | 单位转换证明未实现 |
| 20 | 可退款被回答不可退款 | 中文否定语义未验证 |
| 48 | 自然语言工具报告未发货 | 工具不是已支持的 success/data JSON |

这些有足够人工证据，不因为机器不懂就把它们从 False Gap 分母删掉。原/新审核都拒绝同样八条；修复没有解决通用语义审核问题。当前结果仅支持“两个安全缺陷修复未在本集新增误拒”，不做统计显著性或总体零退步承诺。

此外还有三个真值正确的原候选被拒：跨线程、伪造摘录、漏引用户约束。这些不算证据足够的误拒，计入 trueObservationRejects，与八条真正证据缺口合计 11。

## 多故障、恢复和重放

case-33 同时存在参数与答案错误、另有侧路工具异常，保留两个语义观察但不归因到唯一内部模块。case-34 早期工具错误后答对，A 可以报告发生过显式异常，语义方案不因此指控最终答案错误。case-35 有无关显式异常和独立答案矛盾，不能把并存当因果。

case-24/25 相同结果重复（含格式差异）可引用任一事件；case-26 新调用身份重试可观察旧值使用；case-27 身份复用的 Call 重放无法确定尝试关系而保守拒绝。这个保守范围可能在真实 idempotent 事件流中增加人工复核，未做生产验证。

## 标签与评估风险

标注由单一作者完成，没有独立语义复核；尤其同义表达、否定和单位的真值判断应后续独立复核。初版 supportable 混淆“人可验证”与“机器已实现”，在正式运行前保留字节并另层修订，没有在正式结果后改标签。根因候选未知不等于底层局部观察不存在，另补有限观察标签，两者分开保存。

候选与 B 共享结果解析，可能共用同一种错误。合成轨迹的显式 success 和 orderId 假定可信，不能证明真实外部世界状态；缺 span、并发与权威来源选择仍可能导致错误。遗留 assert 验证继承自旧候选，本轮按普通 Python 模式测试，未验收 -O 运行，不应将此原型直接用作公开安全边界。

## 后续方向（未实现）

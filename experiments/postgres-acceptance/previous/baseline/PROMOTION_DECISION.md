# 决策：保留 Shadow，不推广

两个已披露缺陷已修复并做回归。48 例固定人工候选下，旧审核 8 个不受支持接受降为 0，False Gap 保持 8；没有为了覆盖率接受无证据根因。这支持保留新候选，但不支持生产集成。

| 条件 | 证据 / 状态 |
| --- | --- |
| 保留原平台与旧结果 | 上轮 54 个文件、平台关键 10 个文件未变；默认行为未改 |
| 局部修复可解释可复现 | 两个红绿探针、14 项开发测试及变形测试通过 |
| 原相关链回归 | 旧 Shadow 原版15、原 Python36、TS桥接71、新增18通过；未改旧15测试换新版为12通过/3不适配，政策收紧明确披露 |
| 误支持降低 | 当前单作者合成集 8→0，有限通过 |
| 不显著增加误拒 | 本集旧/新均 8；未有总体显著性证据 |
| 超过合理规则的真实 LLM 增量 | **未证明**；旧真实六例的有效 LLM-only=0，新复杂集未调用模型 |
| 自然语言/复杂负例可靠性 | 八条人工可支持观察仍误拒；合成负例安全不等于线上鲁棒 |
| 严格独立质量验收 | **不满足**，同一作者；本轮冻结流程已完成，但不能冒充独立盲测 |
| 成本收益 | **未验证**，新模型调用0；没有用旧成本预测新复杂任务 |

因此不合并默认链、不新增数据库字段、不启用模型收费和生产 Trace 外发。新版本只是 candidate/ 的独立离线 Shadow。

## 关闭、恢复与可回滚性

不运行本目录实验即可关闭，没有 worker 或后台任务在生产注册。原版在 previous/，平台未改，不需要反向迁移或覆盖旧平台文件。previous 与上轮目录哈希比较可复核，正式结果不允许原地覆盖。保留原 11 月 10 日 ZIP、历史第三轮负结果及回滚记录。

## 什么条件下再讨论可选集成

1. 经授权的新真实模型预算，冻结新 Prompt 后采集复杂集 C 原始输出。不要删除旧调用账本冒充新预算。
2. 独立标注与复核新的未披露数据，包含自然语言、多轮、恢复和身份冲突，区分观察与根因。
3. 明确八类语义缺口如何获得可靠支持；若只能人工判定，就维持 Needs Review，不用第二个模型自信投票替代证据。
4. 若真实 C+D 相对 B 有额外正确且证据支持观察，同时误支持/误拒及费用可接受，再给出复用 ModelRuntime 和原独立任务的默认关闭集成建议。

以上是后续条件，不是已实现功能。本轮没有足够证据声称 LLM 必要性，也没有足够证据断言 LLM 在所有复杂任务中无用。

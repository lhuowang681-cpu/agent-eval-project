# 实验结果：可验证语义观察，暂不推广

**已实现、已运行**：独立候选合同、受限模型调用、三类局部证据审核、原规则对照、逐案例指标与少量真实 DeepSeek 调用。模型在 6 条合成轨迹上产生 6 条正确且可支持的观察，覆盖其中 4/4 个语义错误案例；原规则覆盖 0/4。两个正常/已恢复案例均弃权。

这证明了小样本可运行性，**不能证明真实生产效果或独立泛化**。审核在这 6 次真实调用中没有比直接 LLM 多减少错误；其拒绝能力主要在刻意构造的人工候选回放中验证。

## 数据、口径与可复核性

- `data/dev.jsonl`：12 条新合成开发例。
- `data/holdout.jsonl`：24 条新合成后续测试例，15 个可观察语义错误案例、19 个目标类别；不是第三轮旧 28 例。
- 同一作者编写模板与标签，未使用模型/审核器反向生成 gold，但知道所有场景。测试前哈希冻结未成功，后续又补了健壮性检查；不能宣称严格未见、独立作者测试。
- `data/MANIFEST.json` 固定数据字节；整个实验没有修改现有 JSONL/Gold。存在标签粒度不足：missing 的早期布尔 truth=false 不能证明结论错误，最终评估将其记不可判而非正确/错误，原数据未改。
- `fixtureCandidate` 是人工固定候选，**不代表模型推理**。真实调用仅发送 trajectory，不发送 kind、labels 或 fixtureCandidate。
- `results/*-holdout.json`、`replay-dev.json` 保存逐条候选、规则结果、审核原因和调用 usage；`per-case.csv` 是 42 组案例执行 × 3 方法，共 126 行，真实 6 条与回放 24 条重叠，不能当 42 条独立轨迹。
- `summary.json` 为最终统计；`*.initial-metrics.json` 和旧 summary 文本保留初版指标错误，不作为结论。修订见 `EVALUATOR_CHANGELOG.md`。

### 指标定义

事实正确：对照作者预设的字段关系，A 为 year 2025→2024，B/C 为 status pending→shipped；必须是 observation。不是按模型自报 confidence 或审核器自己投票判真。当前不评估模型自由摘要的自然语言正确性，审核输出只承诺规范化字段命题。

证据支持：事实正确，且必要字段引用存在、scope/digest 一致、必要新旧节点齐全。False Support 为被接受但不满足上述独立检查的声明；False Gap 为原始候选中满足上述条件、却在审核后丢失的命题数量。它不是全部漏检数。

有效覆盖：至少有一条正确且有支持观察的语义正例数 / 语义正例数。另报类别命中数，避免多故障只检出一条却称全部检出。引用有效率只是原文存在率，不代表结论正确。错误归因按错误有限观察统计，根因/影响推断不可判，根因准确率 NA（未验证根因数为 0）。

UNKNOWN / ABSTAIN 不计正确。弃权率为无输出案例 / 所有案例，包含正常负例的合理弃权。无输出时接受准确率和风险为 NA，不写 100% 或零风险。

## 对照一：24 条人工候选回放（非真实 LLM）

| 方法 | 观察/声明数 | 正确 / 错误 / 不可判 | 有效语义覆盖 | 类别检出 | 引用有效 | 弃权案例 |
| --- | ---: | --- | --- | --- | --- | --- |
| A 原规则 | 2 | 2 / 0 / 0 | 0/15 | 0/19 | 4/4 | 22/24 |
| B 人工直接候选 | 21 | 16 / 2 / 3 | 8/15 | 12/19 | 40/44 | 7/24 |
| C 人工候选 + 新审核 | 12 | 12 / 0 / 0 | 8/15（53.3%） | 12/19（63.2%） | 26/26 | 16/24 |

规则正确识别两个显式外部工具失败，但不能发现结构化语义偏差。人工候选审核前的 16 个正确命题不都具有可用引用：伪造引文、跨 scope 的命题即使碰巧事实正确，也不能接受。

C 的被接受有限观察准确率 12/12、False Support=0、False Gap=0。还有 7 个语义正例没有有效输出，原因是该例提供的候选引文/身份错误、比较值错误或强行作根因声明；**False Gap=0 不代表覆盖完整**。这组风险是刻意设计候选的工程测试结果，不是 LLM 的真实错误分布。

开发集 12 条：规则正确显式观察 1 条、语义覆盖 0/8；人工直接候选正确 8、错误 1、不可判 2；审核保留 6 条正确观察、覆盖 4/8、类别 6/10，False Support/False Gap 均 0。开发和测试重复机制，不能据此论证泛化。

## Token、延迟与费用

实际返回 usage：输入 **6434** Token（缓存命中 640、未命中 5794），输出 **1103**，合计 **7537**；模型请求总墙钟时间 **12.372 秒**，平均 **2.062 秒**、最大 **4.005 秒**。不包含整个平台执行延迟；本轮没有测大规模吞吐。

按 2026-11-10 查询的 [DeepSeek 官方价格](https://api-docs.deepseek.com/quick_start/pricing/)，Flash 高峰每百万 Token 输入命中 $0.006、未命中 $0.3、输出 $1.2，低峰减半。六次估算合计 **$0.00153282–$0.00306564 USD**。供应商响应未返回账单金额，未核对实际扣款，actualBill=null。没有把估算写成真实收费。

## 典型拒绝、误拒与未覆盖

完整逐条原因在 `results/rejections.json`。

| 类型 / 例子 | 原因 | 处理是否合理 |
| --- | --- | --- |
| fake / holdout7 | quote 不在原字段 | 拒绝，不能用正确猜测代替证据 |
| scope / holdout8 | 借另一个 Case 的 scope | 整批 needs_review，原评测不动 |
| wrong / holdout9 | 原结果 pending，却声称 expected=cancelled | 引用真实但比较错误，拒绝 |
| root / holdout10 | 局部矛盾被强行写 root_cause | 因果证据不足，拒绝；真值不可判 |
| missing / holdout11 | 工具节点缺失 | 引用失效，结论不可判；不能因缺失而判对 |
| 合法短摘录（单元测试） | 仅引 pending，但同一被引字段内有 success/data/orderId | 接受有限字段关系，不要求整字段逐字引文 |
| 自然语言回答（单元测试） | 没有可验证 JSON 字段 | needs_review；当前能力限制，可能漏掉真实语义错误 |

在当前被提供的、独立字段关系可验证候选中，没有观察到审核误拒（False Gap=0）；但单作者狭窄合成集不能证明无误拒，尤其自然语言命题不在已验证合同内。

## 回归与边界

原 Python **36/36**、原 TS↔Python/Trace/任务 **71/71**、新增 unittest **15/15** 通过，日志和命令见 results。新测试含本机真实 HTTP Mock、空响应/非法 JSON/截断、超时异常、假引用、scope、重复节点/顺序、同字段短摘录、类型比较和无因果背书。

最初沙箱内本机网络测试失败，原始失败日志保留；允许本机 HTTP 后复测通过。这是测试环境限制，不曾用跳过 Mock 冒充成功。35 秒超时只有异常路径的确定性 Mock，不是供应商真实长超时实验。

没有重跑历史 945 项、真实 PG/UI、全库类型检查。生产 Trace、真实脱敏 gold、自然语言支持、工具权威/时效、复杂并发和付费取消都未验收。最终结论：**新增 LLM 在该小样本弥补了规则的三类语义盲区；新增审核在人工对抗候选上降低无依据接受，但真实模型条件下的收益与风险尚未充分验证。保留 Shadow。**

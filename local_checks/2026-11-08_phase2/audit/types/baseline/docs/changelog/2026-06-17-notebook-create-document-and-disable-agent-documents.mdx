# Notebook createDocument Fix and Agent Documents Disabled 📓

This release makes Notebook document creation more forgiving for weaker models, and temporarily disables Agent Documents so users are not surprised by agent-scoped documents filling the conversation context.

## 🐛 Bug Fixes

- 📓 **Notebook `createDocument` works without `content`**: When the agent omits the body, the tool now falls back to `description`, then an empty string—instead of failing validation. This reduces errors from models that only pass title and description when creating a placeholder document.

## 🌟 Key Updates

- 🚫 **Agent Documents tool disabled for agents**: The Agent Documents builtin is no longer exposed to agents, even if it was previously enabled on an agent profile. This prevents accidental creation of agent-scoped documents that pollute context and confuse users. Progressive loading for agent documents is planned for a future update.

## 💡 Tips

- Use **Notebook** to save topic-scoped notes, reports, and drafts the user can review in the sidebar.
- If you need shared agent-level working files today, wait for the upcoming progressive-loading experience rather than relying on Agent Documents in chat.

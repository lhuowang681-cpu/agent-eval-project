# Cloud Sandbox Document Skills and Session Renewal 📁

This release adds Office document processing in cloud sandbox conversations, along with better session renewal and file reuse—making document workflows smoother and more reliable.

## 🌟 Key Updates

- 📄 **Word (.docx)**: create reports, memos, and contracts; read and summarize content; edit text and formatting; handle tracked changes and comments; convert `.doc` to `.docx` or export to PDF
- 📊 **Presentations (.pptx)**: build decks from scratch or update templates; read and summarize slide content; check layout issues (overlap, clipping, contrast, etc.)
- 📑 **PDF**: extract text and tables; merge/split PDFs; rotate pages, add watermarks, fill forms; OCR for scanned documents
- 📈 **Excel (.xlsx / .csv)**: analyze data, create/edit spreadsheets and formulas, clean messy data, append to existing workbooks
- ⏱️ **Session renewal**: automatically extends active sandbox sessions when you continue chatting in the same topic
- 🔄 **Exported file reuse**: after sandbox expiration, previously exported PPT/Excel files are restored in follow-up turns so the AI can keep editing

## 💡 Tips

- Continue in the **same topic** to benefit from renewal and file reuse
- Specify the desired **output format** (Word / PPT / Excel / PDF)
- After export, say “edit the PPT from earlier”—no need to re-upload

## 💫 Experience Improvements

User uploads and AI-generated outputs are handled separately, so the AI better understands original inputs vs. editable deliverables—without you managing file paths manually.

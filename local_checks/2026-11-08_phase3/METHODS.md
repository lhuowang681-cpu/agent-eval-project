# 数据、五组对照与指标合同

## 来源和隔离

开发集12例来自已公开的第二阶段合成边界，明确参与诊断；本轮重新区分事实真伪与证据不足，不把伪引文自动标成事实错误。独立作者另写28例holdout；优化方案和代码SHA冻结后才向主实现者开放具体输入/标签，之后不再改算法。另四条是第二阶段真实PostgreSQL/Agent执行的保存轨迹，任务与模型响应为合成/Mock，只做工程回放，不冒充生产真实数据。

holdout有24个可观察事故正例、12个已知合成机制标签。根因真值来自作者设定的合成世界，未实际向平台注入那些机制；仅用于检验统计与弃权行为，不是人工复核的真实根因gold。历史XLSX来源审计不纳入质量评测，原文和原始用户标识不复制。

优化前后各版本9文件均冻结并有SHA。worker每个版本单独子进程加载，stdin仅含id/trajectory/candidate，绝不接收labels；同一候选回放到各组，没有重新生成候选。原版和优化版正式holdout各执行一次；后续只重算指标，不重跑或调算法。

## 五组条件

| 组 | 输入/处理 | 被评估输出 |
| --- | --- | --- |
| 规则Baseline | 原adapter.analyze，无完整审核 | 原top-level diagnosis，observations另存 |
| 直接LLM（离线候选） | 固定人工候选原样回放，无审核 | 原候选完整命题 |
| LLM＋结构审核（离线） | 固定字段/类型/14类别/56模块/引用形状 | 原候选或弃权 |
| LLM＋引用有效性（离线） | 结构＋当前轨迹节点/原字段精确引文；具体结论须有引用 | 原候选或弃权，不检验因果支持 |
| LLM＋完整审核（离线） | 原/优化版audited_candidate，支持性/范围/摘要政策 | 新生成的规约有限观察或弃权 |

“LLM”是目标部署中的位置，**本轮这些组没有真实LLM推理**。人工候选夹具不是模型能力样本，第二阶段localhost SDK回显也不是推理。不得写真实LLM准确率、胜率或供应商成本。ModelRuntime本轮不改，没有确认真实配置则标blocked。

完整审核的safeCandidate会规约summary/status/reasonCodes，因此其正确性属于新有限命题；不能把它的正确性转记为原LLM自由因果文本正确。规则与审核共享分类函数，存在相关性和模板偏置，不能当两个独立裁判。

## 指标与分母

具体类别非null、module非null或claimLevel=root_cause即正向claim。没有具体结论的UNKNOWN/null/审核弃权不算正确；执行异常单列。status=unknown却同时声明具体类别，也不能靠状态名躲掉错误统计。

| 指标 | 计算 |
| --- | --- |
| 根因分类准确率（全部已知标签） | module＋category匹配的root命题/全部root-known例；弃权和执行失败均不给正确分 |
| 已输出已知根因准确率 | 正确root命题/已输出且具有已知真值的root命题；无输出为null |
| 已知错误归因率 | 独立标签判false的正向命题/全部例；不可判定单列，不把“不支持”自动当事实错误 |
| 选择性错误风险 | 已知错误/可判定的已输出命题；同时给judgedCoverage和unjudgedCoverage |
| 全输出风险上下界 | [已知错误/全部claim, (已知错误＋不可判定)/全部claim]；无claim为null，不宣称零风险 |
| 引用有效率 | 同轨迹节点/合法原字段/精确非空引文存在的引用数/全部引用数；不包含支持性判断，无引用为null |
| 被接受结论准确率 | 正确/可判定的实际输出；不可判定数量同步展示，无输出为null |
| 被接受结论支持率 | 独立裁决支持/已裁决的实际输出；支持未知单列，另给全claim支持区间 |
| 有效观察覆盖 | 类别正确、引用有效且独立支持的有限观察例/可观察事故正例；root命题不冒充观察 |
| 作答覆盖、根因覆盖 | 正向命题/全部例；root命题/全部例，分别报告 |
| 弃权率 | 非执行异常且没有正向命题/全部例；根因弃权同样排除执行异常，另列含异常的无root率 |
| 误拒绝 | 原候选整段正确、给定证据支持且有claim，但完整审核没有输出；执行异常单独，不算策略误拒 |

支持性不能从observationEligible自动推导。holdout冻结时ruleCanonicalSupported仅为轨迹资格，首次报告将其置null并标待裁决；后续对实际输出去掉方法/审核信息，另请代理核对对应类别和具体引用，结果另存adjudication，不修改冻结oracle。safeCanonicalSupported只适用于相同候选类别和现有引用的有限重写。该复核仍是内部代理，不是独立人类gold。

风险—覆盖率使用五个固定审核强度的离散操作点，没有置信度分数，不伪造连续阈值曲线。每点保留可判定与不可判定人群，不将高弃权宣传成高准确率。根因和观察须分层解读；混合claim点只能表示整个输出政策的工程风险。

本地计时是规则/审核函数的perf_counter wall time，另存整个子进程耗时；非模型推理延迟，不作单次微秒差异性能结论。Token、真实模型延迟、供应商费用均null（未测），不是0。小规模人为集无iid假设，不提供虚假统计显著性；零观测错误不证明真实风险为零。

逐例完整结果在results各split的baseline-outputs/optimized-outputs.json，指标和离散风险点在comparison；最终经输出裁决的统计另存comparison-adjudicated，原首次结果保留。

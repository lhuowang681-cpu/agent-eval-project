# Task Tools Routing and Executor Fix 🛠️

This release fixes a long-standing issue where `lobe-task` tool calls would hang forever, sharpens the routing between `lobe-task` and `lobe-gtd` so the agent picks the right tool for scheduling requests, and cleans up obsolete Task Skill references.

## 🐛 Bug Fixes

- 🔧 **`lobe-task` tool calls no longer hang**: Previously, any `lobe-task/*` call (e.g. `createTask`, `listTasks`, `setTaskSchedule`) would stay in "loading" forever without an error — the executor was implemented but never registered in the frontend executor registry. We added the `./executor` subpath export on the package and registered `taskExecutor` alongside the other builtin executors.

## 🌟 Enhancements

- 🧭 **Clearer routing between `lobe-task` and `lobe-gtd`**:
  - `lobe-task` meta description now highlights **automated scheduling (cron / heartbeat / periodic execution)**, so requests like "every day at 10am …" hit the right tool at selection time.
  - `lobe-gtd` meta description now explicitly describes its background tasks as **one-shot**, and points users to `lobe-task` for recurring automation.
  - Both tools' system prompts now carry a short routing section (`<when_to_use>` / `<vs_task_tools>`) that spells out the boundary and handles Chinese and English trigger words (定时 / 每天 / 每周 /cron/schedule/periodically/heartbeat).
- 🧹 **Removed obsolete Task Skill references**: The `task` skill under `packages/builtin-skills` described an `lh task` CLI that isn't implemented in `@ctrip/tripyoyo-cli`. Its registration has been removed from the builtin-skills index and from the taskRunner plugin list. The skill source files are kept on disk but are no longer loaded.

## 💡 Rule of Thumb

| User intent                                                    | Tool                            |
| -------------------------------------------------------------- | ------------------------------- |
| 定时任务 / 每天 /cron/periodic/recurring                             | `lobe-task` (`setTaskSchedule`) |
| Quick todo checklist / plan doc / one-shot background research | `lobe-gtd`                      |
| Structured tasks with subtasks, dependencies, agent assignment | `lobe-task`                     |

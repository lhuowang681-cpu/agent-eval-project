# 云沙箱文档技能与续期优化 📁

本次更新为云沙箱对话新增 Office 文档处理能力，并优化沙箱续期与文件复用体验，让 AI 帮你处理文档时更连贯、更可靠。

## 🌟 重要更新

- 📄 **Word 文档（.docx）**：生成报告 / 备忘录 / 合同，读取与总结内容，编辑文字与格式，处理修订与批注，支持 `.doc` 转 `.docx` 或导出 PDF
- 📊 **演示文稿（.pptx）**：从零制作或基于模板更新 PPT，读取并总结每页要点，检查版式问题（重叠、裁切、对比度等）
- 📑 **PDF**：提取文字与表格，合并 / 拆分 PDF，旋转页面、添加水印、填写表单，扫描件 OCR 识别
- 📈 **Excel（.xlsx / .csv）**：数据分析与统计，创建 / 编辑表格与公式，清洗不规范数据，在已有表格上追加内容
- ⏱️ **沙箱续期**：在同一话题内继续聊天时，自动延长未过期沙箱的使用时间，减少反复从头开始
- 🔄 **导出文件复用**：沙箱过期后，此前成功导出的 PPT、Excel 等文件可在同话题后续对话中自动找回，AI 可直接继续编辑

## 💡 使用建议

- 尽量在 **同一话题** 内追问，以享受续期与文件复用
- 说明期望的 **输出格式**（Word / PPT / Excel / PDF）
- 文件成功导出后，可直接说「继续改刚才那份 PPT」，无需重新上传

## 💫 体验优化

区分用户上传附件与 AI 生成文件，AI 能更准确地理解「原始输入」与「可继续修改的产出」，对话中无需手动管理文件路径。

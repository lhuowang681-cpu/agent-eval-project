# Using Ada in LobeYoYo

<Image alt={'Using Ada in LobeYoYo'} cover src={'https://hub-apac-1.lobeobjects.space/docs/ada-cover.png'} />

Ada provides a unified gateway for curated chat models via Anthropic-compatible API. It supports models such as Claude Sonnet 4.6, Claude Haiku 4.5, Qwen3.6 Plus, and GLM-5.1. This guide will walk you through how to use Ada within LobeYoYo:

<Steps>
  ### Step 1: Obtain Your Ada API Key and Endpoint

  - Sign up for an Ada platform account;
  - Go to the Ada platform dashboard and obtain your API key;
  - Copy the Endpoint URL (Anthropic-compatible) from your application settings;
  - Make sure your application has access to the models you want to use.

  ### Step 2: Configure Ada in LobeYoYo

  - Navigate to the `Settings` page in LobeYoYo;
  - Under `AI Providers`, locate the configuration section for `Ada`;

  <Image alt={'Enter your API Key and Endpoint'} inStep src={'https://hub-apac-1.lobeobjects.space/docs/ada-config.png'} />

  - Paste the API key you obtained earlier;
  - Fill in the Endpoint URL;
  - Choose an Ada model (e.g., `Claude Sonnet 4.6`, `Claude Haiku 4.5`, `Qwen3.6 Plus`, `GLM-5.1`) for chat.

  <Image alt={'Select an Ada model for chat'} inStep src={'https://hub-apac-1.lobeobjects.space/docs/ada-model-select.png'} />

  <Callout type={'warning'}>
    Please ensure that your Ada platform application has been granted access to the model you want to use before enabling it in LobeYoYo.
  </Callout>
</Steps>

And that's it! You're now ready to use Ada's curated chat models in LobeYoYo.
